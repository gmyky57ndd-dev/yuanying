## 0. 执行摘要

当前系统存在**两个独立故障**，分别位于 PWA 前端和采集器数据流。二者不相关，必须分开处理。

| # | 故障 | 严重度 | 影响范围 | 负责 |
|---|---|---|---|---|
| F1 | PWA 4 个信号按钮点击无反馈 | **P0** | 用户无法记录任何信号 | 前端 |
| F2 | 元婴在对话中编造按钮含义 | **P0** | 产品信任崩塌，违反核心原则 | 前端 + Prompt |
| F3 | 采集器数据是否写入 Supabase 未验证 | **P1** | 采集器可能只是 UI 壳 | Android + 后端 |

**修复优先级：F2 > F1 > F3**

**理由**：F2 直接违反《产品意图简报》的核心原则（“不确定时说不确定”）。一个会编造的元婴，比一个按钮不工作的元婴更严重。

## 2. 期望行为定义（Requirement）

**本节是本次任务的核心。分诊和修复前，工程团队必须理解“做对了是什么样”。**

### 2.1 PWA 4 按钮的期望行为

| 按钮 | 点击后立即发生 | 后端行为 | 长期行为 |
|---|---|---|---|
| **wake** | 按钮变绿 | POST `/api/signal` `{name:"wake"}` | 当日重复点击返回已有记录 id，不新建 |
| **sleep** | 按钮变绿 | POST `/api/signal` `{name:"sleep"}` | 同上 |
| **water** | 按钮显示 "water ×N" | POST `/api/signal` `{name:"water", value:1}` | 每次点击累积，N 递增 |
| **sit** | 按钮变绿 | POST `/api/signal` `{name:"sit"}` | 当日重复点击返回已有记录 id，不新建 |

**关键细节：**

1. **立即反馈**：点击后 ≤100ms 内 UI 变化（乐观更新），不等服务器
2. **持久化**：刷新页面后状态保持
3. **幂等性**：wake/sleep/sit 当日不重复；water 可累计
4. **错误可见**：任何失败（网络、4xx、5xx）必须有用户可见提示，不允许静默失败
5. **数据可查**：每次点击后，Supabase `signals` 表中应有对应记录

### 2.3 采集器的期望行为

**用户授予权限后**：

1. WorkManager 每小时触发一次
2. 调用 `UsageStatsManager.queryAndAggregateUsageStats(now - 1h, now)`
3. 过滤 foreground < 1 分钟的 app
4. POST 到 `/api/activity`
5. 服务端写入 `signals` 表（name=`app_usage`）
6. 用户可在 Supabase 中查询到记录

**用户点击“立即上报一次”后**：

- 立即触发一次采集
- 数据出现在 Supabase `signals` 表
- UI 显示“已上报 N 个应用”

- WorkManager 是否真的在后台运行
- 数据格式是否符合 schema

```
async function logSignal(name: string) {
  // 1. 乐观更新：立即变绿
  const optimistic = {
    id: -Date.now(),
    name,
    created_at: new Date().toISOString(),
  };
  setTodaySignals(prev => [...prev, optimistic]);
  
  // 2. 发送请求
  try {
    const res = await fetch(
      `${window.location.origin}/api/signal`,
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ name }),
      }
    );
    
    if (!res.ok) {
      const err = await res.json().catch(() => ({}));
      console.error('signal failed:', res.status, err);
      alert(`信号记录失败：${res.status}\n${err.error ?? '未知错误'}`);
      // 回滚
      setTodaySignals(prev => prev.filter(s => s.id !== optimistic.id));
      return;
    }
    
    // 3. 用服务器数据校准
    await loadSignals();
    
  } catch (err) {
    console.error('signal network error:', err);
    alert('网络错误，信号未记录');
    setTodaySignals(prev => prev.filter(s => s.id !== optimistic.id));
  }
}

```
